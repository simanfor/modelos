[SIMANFOR](https://www.simanfor.es) is a Decision Support System that allows the simulation of forest management alternatives.

In this repository, you will find datasheets describing the content of each model, their structure, and requirements for use.

## 📜 Content

### 👉 List of all models available at SIMANFOR and additional information [here](./english/detailed_model_list.md)

* **espanol**: contains model sheets in Spanish 🇪🇸
* **english**: contains the model sheets in English 🇬🇧

In each of the folders, the contents are as follows:

* 🌳 **individual_tree** / **arbol_individual**: individual tree model description sheets:
    * 🌳🌳 for **pure stands**
    * 🌳🌿 for **mixed stands**
    * 🪵🪵 for **yields** (*Existencias España*)
* 🎯 **harvests** / **corta**: short explanation about the harvests settings on SIMANFOR
* 🌳🌳 **stand** / **masa**: descriptive datasheets of stand-level models
* 📖 🇪🇸 **SIMANFOR_modelos.pdf**: Explanation of the operation of forest models in SIMANFOR in Spanish
* 📖 🇬🇧 **english/SIMANFOR_models.pdf**: Explanation of the operation of forest models in SIMANFOR in English
